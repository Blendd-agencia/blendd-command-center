# Editorial templates, memory and generation

The client backoffice exposes Templates e memória. Resources live under each client's `social.ruleResources[ruleId]`; the same structure handles the free-content rule. Templates keep a version, private PNG/JPEG preview, optional PDF reference, editable-source URL, dimensions/format, slide count and written layout limits. Binary assets reuse the existing private upload path and quotas. Backup reference validation includes these assets.

Feedback remains on its source post. An administrator may explicitly promote it to an active rule for that rubric; unconfirmed entries stay inactive. Edits retain the previous text/status. General briefing sections and only the selected rubric's instructions, active rules, chosen template and associated materials enter the prompt. Unknown briefing sections are excluded unless marked `aiScope: general`. The initial Tec Labs general sections are position, channels and visual; no combined all-rubric summary is sent.

POST /api/editorial-ai authenticates an administrator, checks origin and workspace revision, reads the authoritative client/post/materials and reserves a durable operation before invoking AI Gateway. The server uses the current Vercel OIDC request header, or a server-only AI_GATEWAY_API_KEY. Model fixed to openai/gpt-6-astra, verified in the gateway catalog on 2026-11-11. Chat Completions uses low reasoning, no temperature, and a JSON schema. No public credentials or automatic posting. PNG/JPEG previews use high-detail visual input; exact typography/layout constraints should be written in the template instructions.

Initial test limits: 3 new requests per minute, 20 per UTC calendar month across the application. Base context at most 30,000 characters; enriched context at most 60,000 UTF-8 bytes. Up to six material sources, four content images plus one template, 3 MB per source. Images are decoded and reduced to 1600px (25MP input pixel ceiling). Extracted pages are limited to 6000 characters each, 24000 total. Output including reasoning <=6000 tokens; source timeout 15s, provider timeout 75s, function 120s. A conservative USD 1.50 reservation per Astra request is charged against the existing USD 5 monthly test ceiling. Legacy GPT-4.1 jobs count USD 0.25. This is a conservative gate, not invoiced spend. Failed/interrupted operations count conservatively. Limits are atomic in Postgres. A repeated operation ID cannot trigger another model request. Results, errors, token usage and brief/rule/template/memory provenance are stored in cc_ai_jobs with RLS; direct inserts/updates are not granted to authenticated users. No automatic provider retries.

The proposal must be explicitly applied. Client-owned text is preserved, existing post changes block applying an in-flight response, and applying team-owned text invalidates prior approvals. Existing jobs can be reviewed in history. Conflicting server writes retain the existing workspace conflict protection.

This phase generates copy and slide text, not rendered artwork. PDF/editable links are references for humans and are not parsed or filled. Public HTTPS pages, plain text and PNG/JPEG/WebP links are read, including public Drive file download links. Private material images are retrieved only after checking their company and ready status. PDFs, Drive folders, login-only and JavaScript-only pages are not supported; failures are displayed explicitly. Link-only input is accepted only if at least one source is readable. URLs in raw material text are also processed. External requests have no cookies or application credentials; each DNS result and redirect is checked, public addresses are pinned to TLS requests, byte and time limits apply. Sources are untrusted data, never system instructions. Source status and content hashes are recorded in job provenance and shown in proposal/history. Final artwork rendering requires choosing an editor/rendering integration after the real templates are supplied.

Verification: unit/API tests mock the paid provider; database reservation/idempotency tests run with rollback. A successful deployment is not proof of available AI Gateway credit/access. The GPT-4.1 path has one successful real generation. The first authenticated Astra generation remains the live model-access and editorial-quality test. No real customer post was generated or overwritten during setup.

## Client costs
The internal client page shows a monthly consumption card, scoped to the selected client and calendar month in Europe/Lisbon. The API filters by client and date and paginates the full month, independently of the 50-item global history. Each request shows its model and estimated USD cost from recorded input, cached input and output tokens. New jobs preserve the rate snapshot; legacy jobs are labelled estimates using documented model rates. Failed responses retain available provider usage, including invalid JSON and incomplete generations. Requests never sent to the provider have zero provider cost; interrupted requests without returned usage are explicitly unknown and excluded from the displayed subtotal, never assumed free. Reservations are never added to estimated spend. This does not reconcile billing, credits, taxes, hosting or storage.
